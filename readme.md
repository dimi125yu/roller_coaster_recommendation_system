# Roller Coaster Recommendation System

## Description

This project is a recommendation system for roller coasters mainly at amusement parks in the United States. Given specific prompts, a list of roller coasters will be returned tailored to the individual's preferences and location.

## How to Use the Tool

To use this tool, first see cleaning.py

You will download the data from kaggle at the provided data source and replace the directory in cleaning.py with your own.

```
directory = '/Users/robert/Desktop/rollercoaster/coaster_db.csv'
```

Afterwards, run the program and fill in the respective inputs properly
